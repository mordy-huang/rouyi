## 一、服务器初始化（买了服务器做一次）

```bash
ssh root@8.163.121.116

# 安全组放行：22、80、8080

# 装 Docker
curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | apt-key add -
add-apt-repository "deb [arch=amd64] https://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable"
apt update && apt install docker-ce docker-compose-plugin git -y
systemctl start docker

# 克隆代码（服务器上需要 docker-compose.yml）
cd /opt
git clone https://github.com/mordy-huang/rouyi.git
```

## 二、本地准备基础镜像（做一次）

```powershell

ssh root@8.163.121.116 "docker load -i /root/base.tar"
```

## 三、首次部署（做一次）

```powershell
cd C:\Users\zhou\Desktop\RuoYi-Vue-master

# 1. 编译
mvn clean package -DskipTests
cd RuoYi-Vue3-typescript
npm install
npm run build:prod
cd ..

# 2. 构建镜像
docker compose build

# 3. 一包导出所有镜像
docker save mysql:8.0 redis:7-alpine ruoyi-vue-master-ruoyi-admin:latest ruoyi-vue-master-ruoyi-ui:latest -o app.tar

# 4. 上传 + 启动
scp app.tar root@8.163.121.116:/root/
ssh root@8.163.121.116 "docker load -i /root/app.tar && cd /opt/ruoyi && git pull && docker compose up -d --no-build"
```

## 五、日常更新

## 六、常用命令

```bash
# 查看容器状态
docker compose -f /opt/ruoyi/docker-compose.yml ps

# 查看后端日志
docker compose -f /opt/ruoyi/docker-compose.yml logs admin

# 查看前端日志
docker compose -f /opt/ruoyi/docker-compose.yml logs ui

# 重启
docker compose -f /opt/ruoyi/docker-compose.yml restart

# 停止
docker compose -f /opt/ruoyi/docker-compose.yml down
```
